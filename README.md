# Shafwan T.A. — Portfolio

Professional portfolio for [WaannAlter](https://github.com/WaannAlter), a DevSecOps and Infrastructure Engineer with full-stack experience.

The site focuses on collaborative contribution areas across secure software delivery, GitOps, cloud and edge infrastructure, infrastructure as code, embedded Linux, and application engineering. It intentionally avoids exposing private repository content, client details, or unsupported ownership claims.

## Local development

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

## Validation

```bash
npm run build
```

## Reversibility

Every change is tracked in Git. Revert a commit to restore an earlier version, or remove the repository and profile link to take the portfolio offline.

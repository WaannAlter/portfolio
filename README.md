# Shafwan T.A. — Portfolio

Professional portfolio for [WaannAlter](https://github.com/WaannAlter), a DevSecOps and Infrastructure Engineer with full-stack experience.

The site focuses on collaborative contribution areas across secure software delivery, GitOps, cloud and edge infrastructure, infrastructure as code, embedded Linux, and application engineering. It intentionally avoids exposing private repository content, client details, or unsupported ownership claims.

## Public projects

These are modified public editions of private toolkits authored by Shafwan, with synthetic examples and MIT licenses. The repositories document their scope and local test workflows; neither requires paid services.

- [Unified DevOps Tool](https://github.com/WaannAlter/unified-devops-tool) — Rust CLI for project scaffolding, build and security checks, committed-source evidence, and guarded local operations.
- [Veriv Toolkit](https://github.com/WaannAlter/veriv-toolkit) — trusted TOML-defined command and network checks, coverage thresholds, and JSON reports.

## Local preview

Open `index.html` in a browser. The site is plain HTML and CSS with no build step, runtime dependency, analytics, or paid hosting requirement.

## Hosting

The public site is hosted with GitHub Pages from this repository.

## Reversibility

Every change is tracked in Git. Revert a commit to restore an earlier version, or remove the repository and profile link to take the portfolio offline.

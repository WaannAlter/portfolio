devops-toolCommand examples ↗
# Check tools and configuration
$ devops-tool doctor
$ devops-tool validate

# Preview the test plan
$ devops-tool check --target test

Inspect tool availability and validate inputs before running a build.

# Preview a container build
$ devops-tool build

# Run the reviewed plan
$ devops-tool build --execute

Mutating operations preview their plan until you explicitly add --execute.

# Preview the image scan
$ devops-tool scan

# Run the Trivy gate
$ devops-tool scan --execute

The scan requires Trivy and gates high and critical findings.

Veriv Toolkit

Command, HTTP, and TCP checks defined in TOML. Veriv runs a selected set of checks and writes a JSON report with the result of each one.

It supports LCOV coverage thresholds and limits on process time and output. Configuration is trusted code.
